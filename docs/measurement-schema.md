# Measurement table schema

Generated by `scripts/gen_schema_doc.py` from `src/water_aware_coffee/provenance.py`.
Do not edit by hand.

Long format: one row per (place, period, quantity).
`value` is always in the target unit for its quantity:

| quantity | target unit |
|---|---|
| hardness | mg/L as CaCO3 |
| calcium | mg/L Ca |
| magnesium | mg/L Mg |
| alkalinity | mg/L as CaCO3 |
| bicarbonate | mg/L HCO3 |
| sodium | mg/L Na |
| ph | pH |
